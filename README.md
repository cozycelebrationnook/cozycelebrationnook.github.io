# Privacy Policy

CozyCelebrationNook ("I", "my") is a small shop selling original printable products on Etsy.

This policy covers the tool "CozyCelebrationNook Scheduler", a personal tool I use with my own Pinterest business account.

## What the tool does
It creates boards and schedules pins for my own products, and reads statistics of my own account. It is used only by me, the account owner.

## Data
The tool does not collect, store, sell or share personal data of any other person. It only handles content and statistics of my own Pinterest account, and the access token stays on my own computer and is never shared.
